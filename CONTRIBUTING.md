# Contributing

Contributions are welcome, especially fixes that improve ESP32-S3 inference
reliability, RP2040 display behavior, documentation, or reproducibility.

## Useful Contributions

- ESP32-S3 build and flashing fixes
- Model export, quantization, or host verification improvements
- RP2040 display-node wiring and OLED compatibility notes
- Performance measurements on ESP32-S3 boards
- Clearer documentation for setup and demo reproduction

## Pull Request Checklist

Before opening a pull request, please include:

- A short explanation of the change and the reason for it
- ESP32-S3 board, flash size, PSRAM mode, and Arduino core version when relevant
- RP2040 board and OLED controller when display behavior changes
- Notes from host verification, compile, upload, or runtime checks
- Serial output or demo media when generation/output behavior changes

By contributing, you agree that your contribution is provided under the same
license as the project: MIT.
